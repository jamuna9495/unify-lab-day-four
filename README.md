# 🚀 DevConf 2026 - The Future of Web Development

Welcome to the official repository of **DevConf 2026**, India's most influential developer ecosystem. This project is a modern, responsive, and handcrafted web application built using professional CSS layouts like **Flexbox** and **CSS Grid**.

---

## 🌟 Features

- **🎯 Sticky Navigation:** Seamlessly navigate between pages with a fixed header.
- **🔥 Dynamic Hero Section:** High-impact landing page with modern gradients.
- **👥 Speaker Showcase:** Elegant circular profile cards with company badges.
- **📅 Interactive Schedule:** Clean and organized event timeline for attendees.
- **📱 Fully Responsive:** Optimized for desktops, tablets, and mobile devices.

| Technology | Purpose |
